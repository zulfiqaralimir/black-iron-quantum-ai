# black-iron-quantum-ai

## How to start

- **Folder:** open `D:\black-iron-quantum-ai`, then run `claude` in a terminal there.
- **What it is:** a static site (no build step) deployed on Vercel. Pages: `index.html` (home), `claude-partner-network/index.html`, `ferroquant/index.html`. `vercel.json` rewrites `/ferroquant`.
- **Run locally:** open `index.html` in a browser, or serve the folder (e.g. `npx serve .` or `python -m http.server`).
- **Live site:** https://black-iron-quantum-ai.vercel.app (Vercel team `black-iron-quantum-ai`, login `blackiron`).
- **Inputs/outputs:** HTML pages are edited in place; images live in `media/`. Deploy by pushing to `master` on GitHub (`zulfiqaralimir/black-iron-quantum-ai`).
- **History:** the original copy was on an external drive that crashed; this clone (2026-11-08) is the working copy. The older folders `D:\black-iron-quantum` and `D:\blackiron-quantum-ai` are separate/earlier versions.
- **Pending:** nothing recorded yet. Check whether the Vercel project is still linked (`.vercel` is gitignored, so run `vercel link` if needed).
